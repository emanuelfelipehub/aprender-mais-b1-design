# Aprender+ | Módulo B1 Design

Arquivo de design em Figma criado para o módulo B1 do projeto-teste Aprender+, utilizado na preparação para a modalidade Desenvolvimento de Aplicativos Móveis.

O enunciado aborda a experiência de um aplicativo educacional, com fluxos como apresentação inicial, login, cursos, cadastro e perfil. O arquivo `.fig` é a entrega de design deste módulo.

## Abrir o projeto

Importe `08_Modulo_B1_XX.fig` no Figma usando a opção de importar arquivo. O projeto pode ser explorado no editor após a importação.

## Contexto

Trabalho de treino baseado em material de projeto-teste da WorldSkills. O enunciado e os recursos fornecidos serviram de referência para a criação.
